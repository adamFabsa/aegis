These are fictional development fixtures, generated by `npm run seed:fixtures`.
Risk scores, fix effects, values, fuel and fire constants are **simulated defaults**,
not NASA observations or a trained Cal Fire model. A owns replacing/calibrating them.

The admin script accepts buildings.json (including nested fixes), people.json,
fire_cells.json (the complete 50×31 fuel grid), fire_params.json and optional
fixes.json. The JSON wire contract is documented in docs/backend.md. Extra model
features in building seeds are accepted but are not exposed by the fixed public
building schema. D should pass those offline features to the Gemini worker.
