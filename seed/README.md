Generated by the data pipeline (`bash data/run_pipeline.sh` → `data/sim/make_seed.ts`). Do not hand-edit;
change `data/neighborhood.json` or the pipeline and regenerate.

- `buildings.json` — the fictional neighborhood (SIMULATED positions, occupancy, values) with `baseRisk` from the
  CAL FIRE DINS model, construction `features` (for D's explanations), `referenceFireEtaMin`, and per-building
  `fixes` (riskDrop from the DINS model, or from the fire simulation for "Clear brush to 30 ft").
- `people.json` — 260 SIMULATED residents. Maria R. = 1201 (wheelchair), Robert K. = 1202 (oxygen, never replies).
- `fire_params.json` — engine constants calibrated to the 2025 Eaton Fire (NASA FIRMS + IEM wind), the 50×31 fuel
  grid (`fuel`), ignition cells, the hourly wind replay and `fireSeed` (the representative demo fire).
- `staff.json` — staff names for the phones (`phoneStaff`) and the simulated on-site staff.

The same seed is bundled into the module as `spacetimedb/src/seed_data.ts` and loaded on publish (`init`).
`npm run seed` re-sends these files through the admin `seed_world` reducer (validated by `spacetimedb/src/seed.ts`).
